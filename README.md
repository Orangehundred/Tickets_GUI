# Tickets Automation GUI

### Desktop app built with Electron and React that automates ticket creation in our ticket entry website FMX, using Playwright, reducing manual data entry for IT staff.

## Quick Start Guide
1. Check your Node version: node -v
   Requires Node 23 or newer. Download: https://nodejs.org/en/download

2. Install dependencies: npm install

3. Start the app: npm start

## Environment Variables
Edit `creds.env` and fill in your credentials before running.
